
Using a Pi Zero 2 W with Ubuntu 22 64bit:

apt install python3-pip
pip install -r requirements.txt

Install wiringOP-Python into your active Python environment:

chmod +x install-wiringop-python.sh
./install-wiringop-python.sh

# optional: keep temporary build directory for troubleshooting
# KEEP_TMP=1 ./install-wiringop-python.sh

Orange Pi Zero 3 hardware mode:

export MEOWTON_HARDWARE=orangepi-zero3

# optional pin overrides, defaults match current Zero 3 wiring
# export MEOWTON_LED_PIN=2
# export MEOWTON_FOOD_DATA_PIN=9
# export MEOWTON_FOOD_CLOCK_PIN=10
# export MEOWTON_CAT_DATA_PIN=7
# export MEOWTON_CAT_CLOCK_PIN=5

# run smoke tests before full app startup
python hardware_smoke/blink_led.py
python hardware_smoke/read_hx711_once.py
python hardware_smoke/read_hx711_burst.py
python hardware_smoke/pwm_servo_test.py

Container note for Orange Pi board detection:
- wiringOP inside the container reads /etc/orangepi-release or /etc/armbian-release.
- If those files are not mounted into the container, startup can fail with:
	"Oops: Unable to determine board revision ..."
- Use podman-build.sh (not only podman-restart.sh) after script updates so the container is recreated with updated mount flags.

Example systemd service (minimal template):

Create /etc/systemd/system/meowton.service with:

[Unit]
Description=Meowton feeder service
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=root
WorkingDirectory=/app/src
Environment=MEOWTON_HARDWARE=orangepi-zero3
ExecStart=/usr/local/bin/python -u main.py
Restart=on-failure
RestartSec=3
KillSignal=SIGTERM
TimeoutStopSec=20

[Install]
WantedBy=multi-user.target

Apply and verify:

sudo systemctl daemon-reload
sudo systemctl enable meowton
sudo systemctl start meowton
systemctl status meowton --no-pager
journalctl -u meowton -b --no-pager
